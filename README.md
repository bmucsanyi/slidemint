# slidemint

`slidemint` is my `beamer` theme and macro collection. I use it to create slide decks for meetings.

## Requirements

Compile decks with LuaLaTeX, XeLaTeX, or pdfLaTeX. For LuaLaTeX and XeLaTeX,
make the Plus Jakarta Sans and MesloLGS NF font files visible to TeX. XeLaTeX
loads those fonts by file name, so TeX must be able to find
`PlusJakartaSans-VariableFont_wght.ttf`,
`PlusJakartaSans-Italic-VariableFont_wght.ttf`, `MesloLGS NF Regular.ttf`, and
`MesloLGS NF Italic.ttf`.
